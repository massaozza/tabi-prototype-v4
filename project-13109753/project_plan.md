# Japan Quest Guide

## 1. Project Description
A professional inbound tourism website for Japan targeting English-speaking travelers. The site provides destination guides, travel planning tools, and curated content about lesser-known Japanese destinations like Kamakura, Enoshima, and the Shonan Coast. Core value: helping travelers "explore Japan beyond the guidebook" with first-hand local information and AI-powered trip planning.

## 2. Page Structure
- `/` - Home (single-page site with all sections: Hero, Destinations, Budget Calculator, Guides, Features, Footer)
- Future: `/destinations` - All destinations listing
- Future: `/destinations/:id` - Individual destination detail
- Future: `/plan-your-trip` - Trip planning tools
- Future: `/about` - About page
